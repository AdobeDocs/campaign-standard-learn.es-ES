# Creación de espacios de nombres para solicitudes de privacidad

Para poder crear solicitudes de eliminación y de acceso a la privacidad, según lo requerido por el RGPD o la CCPA, debe utilizarse un espacio de nombres para identificar al sujeto de datos en la base de datos de Adobe Campaign.

Aprenda a crear espacios de nombres para solicitudes de privacidad.
